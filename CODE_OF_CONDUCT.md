# Code of Conduct

## Our pledge

We want contributing here to be a reasonable experience for anyone who shows up in good faith,
regardless of experience, background or which CAD software they use.

## Expected behaviour

- Be direct about code and kind about people. Review the change, not the person.
- Assume competence: if someone did something surprising, ask why before rewriting it.
- Accept that "it does not run on my machine" is a report, not an argument — reproduce it or say
  what you could not test.
- Respect model confidentiality. Do not post screenshots, exported scenes or file paths from a
  client project; use the synthetic demo scene (`tools/demogen`) instead.
- Give credit where it is due, in commits and in reviews.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, publishing someone's private information or
client work, and sustained disruption of discussion. Maintainers may remove comments, close issues
or block accounts that do this.

## Scope

This applies in issues, pull requests, discussions and any other project space, and when
representing the project elsewhere.

## Reporting

Report problems to the maintainer listed in the repository profile. Reports are handled privately,
and the reporter's identity is not shared without consent.

## Attribution

This is a short project-specific code of conduct; it follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which
you can consult for the longer form.
